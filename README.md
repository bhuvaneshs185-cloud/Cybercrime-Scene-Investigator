# 🔍 Cybercrime Scene Investigator

A centralized digital forensics dashboard built with Streamlit and SQLite designed for incident response teams and forensic examiners to catalog evidence, maintain cryptographic integrity, and reconstruct security event timelines.

---

## ✨ Features

- 📁 Case Management: Create and track investigations with assigned examiners and case briefs.
- 🛡️ Evidence Custody & Hashing: Upload forensic artifacts with real-time SHA-256 checksum calculation to ensure evidence immutability.
- ⏱️ Event Timeline Reconstruction: Log incident indicators, assign severity scores (1–10), and flag critical-risk findings automatically.
- 🌐 Browser Artifacts Inspection: Track domain visits, access frequencies, and timestamps linked to incident profiles.
